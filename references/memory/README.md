# Memory

`trail.md` is the contract between this pack's artifact trail (`.singularskills/<folder>/<project>/NN-*.md` and `.singularskills/log.jsonl`) and anything that indexes or recalls it: a person, `singular-report`, or a memory system such as `singularrag`. It names where the files are, what their frontmatter and headings mean, which run-log events mark a phase complete or bypassed, and what a memory system should index. The first phase of every workflow bundles a copy and recalls from the trail before it asks the user anything.
