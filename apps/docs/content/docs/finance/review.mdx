## Purpose

The Review phase compares actual financial performance against the budget and forecast, identifies variances, and produces updated forecasts when conditions change materially.

## Prerequisites

All prior phase artifacts should exist in `.singularskills/finance/<project>/`.

## What It Does

<Steps>
<Step>Reads actual results and compares against budget and forecast</Step>
<Step>Calculates variances by department, account, and KPI</Step>
<Step>Identifies root causes for significant variances</Step>
<Step>Determines whether a reforecast is warranted</Step>
<Step>Updates projections if conditions have changed</Step>
<Step>Writes the review to `.singularskills/finance/<project>/06-review.md`</Step>
</Steps>

## Output

<Output>
Creates `.singularskills/finance/<project>/06-review.md` containing:

- Budget vs. actual comparison with variances
- KPI dashboard with target vs. actual
- Variance root cause analysis
- Reforecast recommendations or updated projections
</Output>
