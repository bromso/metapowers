## Purpose

The Scenario utility builds multiple financial scenarios — best, base, and worst case — to understand the range of possible outcomes and prepare contingency plans.

## What It Does

<Steps>
<Step>Defines scenario assumptions for each case (growth rate, churn, pricing)</Step>
<Step>Runs the financial model under each set of assumptions</Step>
<Step>Compares outcomes across scenarios</Step>
<Step>Identifies key decision points and trigger thresholds</Step>
<Step>Documents contingency actions for downside scenarios</Step>
</Steps>

## Output

<Output>
- Three-scenario comparison table (best, base, worst)
- Key metric ranges across scenarios
- Decision triggers and contingency plans
</Output>
