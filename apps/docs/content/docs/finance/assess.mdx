## Purpose

The Assess phase gathers, consolidates, and validates financial data from across the organization, establishing a reliable foundation for planning, forecasting, and budgeting.

## What It Does

<Steps>
<Step>Collects financial data from bookkeeping and accounting outputs</Step>
<Step>Validates data completeness and consistency</Step>
<Step>Normalizes formats and reconciles discrepancies</Step>
<Step>Summarizes current financial position and trends</Step>
<Step>Writes the assessment to `.singularskills/finance/<project>/01-assess.md`</Step>
</Steps>

## Output

<Output>
Creates `.singularskills/finance/<project>/01-assess.md` containing:

- Consolidated financial data summary
- Data quality assessment and gaps identified
- Current financial position overview
- Historical trend analysis
</Output>
