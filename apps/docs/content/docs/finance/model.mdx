## Purpose

The Model phase builds structured financial models — discounted cash flow, comparable analysis, LBO, or custom models — to support strategic decisions such as fundraising, M&A, or investment evaluation.

## Prerequisites

The budget must exist at `.singularskills/finance/<project>/04-budget.md`.

## What It Does

<Steps>
<Step>Selects the appropriate modeling framework for the decision context</Step>
<Step>Builds the model structure with assumptions, drivers, and outputs</Step>
<Step>Links financial statements (income, balance sheet, cash flow)</Step>
<Step>Calculates valuation metrics (enterprise value, equity value, multiples)</Step>
<Step>Writes models to `.singularskills/finance/<project>/05-model.md`</Step>
</Steps>

## Output

<Output>
Creates `.singularskills/finance/<project>/05-model.md` containing:

- Financial model with linked statements
- Valuation outputs and key metrics
- Assumption documentation
- Model structure and driver descriptions
</Output>
