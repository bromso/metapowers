## Purpose

The Sensitivity utility tests how changes in individual input variables (price, volume, cost, growth rate) affect key financial outputs, identifying which variables have the greatest impact on results.

## What It Does

<Steps>
<Step>Identifies key input variables in the financial model</Step>
<Step>Varies each input independently across a defined range</Step>
<Step>Measures the impact on target outputs (revenue, profit, valuation)</Step>
<Step>Ranks variables by sensitivity (highest impact first)</Step>
<Step>Produces tornado charts and data tables</Step>
</Steps>

## Output

<Output>
- Sensitivity matrix with input ranges and output impacts
- Variable ranking by impact magnitude
- Tornado chart data for visualization
</Output>
