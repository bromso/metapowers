## Purpose

The Monitor phase maintains compliance posture after initial certification. Compliance is not a one-time event — regulations change, controls drift, and certifications expire. This phase establishes continuous monitoring, tracks regulatory changes, manages renewal calendars, and produces compliance reports.

## Skills

### Continuous Monitoring

<Command>
{"/compliance:continuous-monitoring <topic>"}
</Command>

Designs a continuous compliance monitoring strategy. Defines automated control testing procedures, compliance metrics and KPIs, drift detection mechanisms, and alerting thresholds for compliance degradation.

<Output>**Output:** Continuous monitoring strategy with metrics and alerting → `.metapowers/compliance/<topic>/04-monitor.md`</Output>

<Command>
{"/compliance:regulatory-watch <topic>"}
</Command>

<Output>**Output:** Regulatory watch process with change management procedures → `.metapowers/compliance/<topic>/04-monitor.md`</Output>

<Command>
