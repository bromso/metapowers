## Purpose

The Journal phase records analyzed transactions as formal journal entries in the general journal, ensuring every entry balances (debits equal credits) and includes proper documentation.

## Prerequisites

The transaction analysis must exist at `.singularskills/accounting/<project>/01-analyze.md`.

## What It Does

<Steps>
<Step>Reads the transaction analysis from the Analyze phase</Step>
<Step>Creates journal entries with date, accounts, debits, credits, and narration</Step>
<Step>Validates that each entry balances</Step>
<Step>Numbers entries sequentially</Step>
<Step>Writes journal entries to `.singularskills/accounting/<project>/02-journal.md`</Step>
</Steps>

## Output

<Output>
Creates `.singularskills/accounting/<project>/02-journal.md` containing:

- Numbered journal entries with dates
- Debit and credit amounts for each account
- Narration and source document references
</Output>
