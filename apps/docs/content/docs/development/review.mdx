## Purpose

The Review skill performs a pre-merge code review, checking for bugs, security issues, code quality, and test coverage before the code is shipped.

## Usage

**Example:**
```
/development:review auth-system
```

## What It Does

<Steps>
<Step>Gathers all changed files (branch diff vs. main)</Step>
<Step>Checks for bugs — logic errors, null handling, race conditions</Step>
<Step>Checks for security — input validation, no secrets in code, no injection vulnerabilities</Step>
<Step>Checks code quality — naming, complexity, consistency, dead code</Step>
<Step>Checks tests — existence, behavior verification, edge case coverage</Step>
</Steps>

## Output

<Output>
Creates `.metapowers/development/<feature>/04-review.md` containing:

- Summary and overall assessment
- Issues by severity (critical, important, minor)
- Strengths
- Recommendations
</Output>
