## Purpose

The Plan skill breaks a feature into bite-sized tasks (2-5 minutes each) with exact file paths, test strategy, and commit points. This is the starting point for any structured development effort.

## Usage

**Example:**
```
/development:plan auth-system
```

## What It Does

<Steps>
<Step>Clarifies the feature requirements and constraints</Step>
<Step>Explores the codebase to understand existing patterns</Step>
<Step>Breaks work into 2-5 minute tasks, each producing a committable state</Step>
<Step>Defines a test strategy for the feature</Step>
<Step>Writes the plan to `.metapowers/development/<feature>/01-plan.md`</Step>
</Steps>

## Output

<Output>
Creates `.metapowers/development/<feature>/01-plan.md` containing:

- Goal and architecture summary
- Numbered tasks with files to create/modify
- Step-by-step instructions per task
- Test strategy
</Output>

## Next Step

After planning, proceed to [Build](/docs/development/build) to execute the plan.
