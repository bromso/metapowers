## Purpose

The Design phase diverges again — this time on solutions. It generates multiple concepts, evaluates feasibility and impact, and recommends the most promising approaches for validation.

## Usage

**Example:**
```
/research-design user onboarding friction
```

## Prerequisites

Requires `.singularskills/research/<topic>/01-discover.md` and `02-define.md` from the Discover and Define phases. Its gate script (`scripts/gate.sh`) stops the skill if either is missing: you cannot design solutions without a defined problem. Use `--skip-checks` to bypass; the skip is logged as a `skipped` event in `.singularskills/log.jsonl`.

## What It Does

<Steps>
<Step>Reads the problem statement and HMW questions from Define</Step>
<Step>Searches for existing solutions, case studies, and best practices</Step>
<Step>Generates 3-5 distinct solution concepts</Step>
<Step>Evaluates each on feasibility, impact, effort, and risk</Step>
<Step>Recommends top concepts for validation</Step>
<Step>Writes solution concepts to `.singularskills/research/<topic>/03-design.md`</Step>
</Steps>

## Output

<Output>
Creates `.singularskills/research/<topic>/03-design.md` containing:

- Problem recap from Define
- Solution concepts with descriptions
- Evaluation matrix (feasibility, impact, effort, risk)
- Prioritized recommendations
- Validation plan for the Deliver phase
</Output>
