## Purpose

The Deliver phase converges on the final recommendation. It validates the top solution concept(s) against evidence, refines the approach, and produces actionable output.

## Usage

**Example:**
```
/research-deliver user onboarding friction
```

## Prerequisites

Requires all prior phase artifacts. Use `--skip-checks` to bypass.

## What It Does

<Steps>
<Step>Reads all prior phase artifacts (Discover, Define, Design)</Step>
<Step>Searches for evidence supporting or contradicting the recommended solution</Step>
<Step>Tests assumptions identified in the Design phase</Step>
<Step>Assesses the solution against success criteria from Define</Step>
<Step>Refines recommendations and identifies action items</Step>
<Step>Writes the final deliverable to `.singularskills/research/<topic>/04-deliver.md`</Step>
</Steps>

## Output

<Output>
Creates `.singularskills/research/<topic>/04-deliver.md` containing:

- Executive summary
- Validation findings with evidence
- Success criteria assessment
- Final recommendation with implementation approach
- Prioritized action items
- Risks and mitigations
- Research journey summary across all 4 phases
</Output>
