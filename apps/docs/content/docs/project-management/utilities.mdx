## Purpose

Utility skills work across all Scrum phases. They have no prerequisites and can be run anytime — for risk management, decision tracking, meeting facilitation, status reporting, or capacity planning.

## Skills

### Risk Assessment

<Command>
{"/project-management-risk-assessment <project>"}
</Command>

Identifies project risks, assesses probability and impact, and defines mitigation strategies. Maintains a living risk register.

<Output>**Output:** Risk register, probability-impact matrix, mitigation plans → `.singularskills/project-management/<project>/risk-assessment.md`</Output>

### Decision Log

<Command>
{"/project-management-decision-log <project>"}
</Command>

Records key project decisions with context, alternatives considered, rationale, and stakeholders involved. Provides an audit trail.

<Output>**Output:** Decision record, alternatives analysis, rationale documentation → `.singularskills/project-management/<project>/decision-log.md`</Output>

### Meeting Facilitator

<Command>
{"/project-management-meeting-facilitator <project>"}
</Command>

Structures and facilitates project meetings — generates agendas, time-boxes discussion topics, captures action items, and produces meeting notes.

<Output>**Output:** Meeting agenda, facilitation guide, action items template → `.singularskills/project-management/<project>/meeting-facilitator.md`</Output>

### Status Report

<Command>
{"/project-management-status-report <project>"}
</Command>

Generates a project status report with RAG indicators, milestone progress, risks, and upcoming activities. Tailored for different audiences.

<Output>**Output:** Status report with RAG status, milestone tracking, risk summary → `.singularskills/project-management/<project>/status-report.md`</Output>

### Capacity Planning

<Command>
{"/project-management-capacity-planning <project>"}
</Command>

Plans team capacity across sprints — accounts for availability, planned leave, skill distribution, and sustainable pace.

<Output>**Output:** Capacity plan, availability matrix, sustainable pace recommendations → `.singularskills/project-management/<project>/capacity-planning.md`</Output>
