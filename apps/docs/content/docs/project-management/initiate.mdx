## Purpose

The Initiate phase establishes the project foundation. Before any planning or execution, you need a clear charter, identified stakeholders, a team structure, a definition of done, and agreed ways of working.

## Skills

### Project Charter

<Command>
{"/project-management-project-charter <project>"}
</Command>

Defines the project scope, objectives, success criteria, constraints, and assumptions. Creates the foundational document that guides all subsequent phases.

<Output>**Output:** Project charter with scope, objectives, success criteria → `.singularskills/project-management/<project>/00-initiate.md`</Output>

### Stakeholder Map

<Command>
{"/project-management-stakeholder-map <project>"}
</Command>

Identifies all project stakeholders, maps their influence and interest levels, and defines communication strategies for each group.

<Output>**Output:** Stakeholder register, influence-interest matrix, communication plan → `.singularskills/project-management/<project>/00-initiate.md`</Output>

### Team Setup

<Command>
{"/project-management-team-setup <project>"}
</Command>

Defines the team structure, roles, and responsibilities. Establishes the Scrum roles (Product Owner, Scrum Master, Development Team) and any extended team members.

<Output>**Output:** Team roster, role definitions, RACI matrix → `.singularskills/project-management/<project>/00-initiate.md`</Output>

### Definition of Done

<Command>
{"/project-management-definition-of-done <project>"}
</Command>

Establishes the shared criteria for when work is considered complete. Covers code quality, testing, documentation, and review requirements.

<Output>**Output:** Definition of Done checklist, acceptance criteria standards → `.singularskills/project-management/<project>/00-initiate.md`</Output>

### Ways of Working

<Command>
{"/project-management-ways-of-working <project>"}
</Command>

Documents team agreements on ceremonies, communication channels, tools, branching strategies, and collaboration norms.

<Output>**Output:** Working agreements, ceremony schedule, tool stack, communication norms → `.singularskills/project-management/<project>/00-initiate.md`</Output>
