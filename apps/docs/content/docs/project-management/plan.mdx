## Purpose

The Plan phase translates the project charter into actionable work. It covers everything from high-level vision and roadmap down to individual user stories, estimation, and sprint planning.

## Skills

### Product Vision

<Command>
{"/pm:product-vision <project>"}
</Command>

Defines the product vision statement, target users, key differentiators, and success metrics. Provides the north star for all planning decisions.

<Output>**Output:** Vision statement, target audience, value proposition, success metrics → `.metapowers/project-management/<project>/01-plan.md`</Output>

### Roadmap

<Command>
{"/pm:roadmap <project>"}
</Command>

Creates a time-boxed roadmap with milestones, themes, and deliverables. Balances near-term commitments with longer-term direction.

<Output>**Output:** Roadmap with milestones, themes, dependencies, and timeline → `.metapowers/project-management/<project>/01-plan.md`</Output>

### Backlog Creation

<Command>
{"/pm:backlog-creation <project>"}
</Command>

Builds the initial product backlog from the roadmap and vision. Prioritizes items using value-effort analysis and organizes them into themes.

<Output>**Output:** Prioritized product backlog, theme groupings, priority rationale → `.metapowers/project-management/<project>/01-plan.md`</Output>

### User Stories

<Command>
{"/pm:user-stories <project>"}
</Command>

Writes user stories with acceptance criteria following the "As a... I want... So that..." format. Includes edge cases and technical considerations.

<Output>**Output:** User stories with acceptance criteria, edge cases → `.metapowers/project-management/<project>/01-plan.md`</Output>

### Story Mapping

<Command>
{"/pm:story-mapping <project>"}
</Command>

Organizes user stories into a story map — activities across the top, user tasks below, with walking skeleton and incremental slices.

<Output>**Output:** Story map, walking skeleton, release slices → `.metapowers/project-management/<project>/01-plan.md`</Output>

### Estimation

<Command>
{"/pm:estimation <project>"}
</Command>

Facilitates story point estimation using relative sizing. Provides reference stories, handles uncertainty, and flags items needing spikes.

<Output>**Output:** Story point estimates, reference stories, spike recommendations → `.metapowers/project-management/<project>/01-plan.md`</Output>

### Sprint Planning

<Command>
{"/pm:sprint-planning <project>"}
</Command>

Plans the upcoming sprint — selects backlog items based on capacity, defines the sprint goal, and breaks stories into tasks.

<Output>**Output:** Sprint backlog, sprint goal, task breakdown, capacity allocation → `.metapowers/project-management/<project>/01-plan.md`</Output>
