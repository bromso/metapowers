## Purpose

The Guidelines phase compiles all brand work into a single, comprehensive brand guidelines document — the source of truth for anyone using the brand.

## Usage

**Example:**
```
/branding:guidelines acme
```

## Prerequisites

Requires all prior phase artifacts, especially `.metapowers/branding/<brand>/04-visual.md`. Use `--skip-checks` to bypass.

## What It Does

<Steps>
<Step>Reads all prior phase artifacts (Discover through Visual)</Step>
<Step>Compiles into a structured brand guidelines document</Step>
<Step>Adds compliance rules (must-do, must-not-do, common mistakes)</Step>
<Step>References all assets in `.metapowers/branding/<brand>/assets/`</Step>
<Step>Writes the guidelines to `.metapowers/branding/<brand>/05-guidelines.md`</Step>
</Steps>

## Output

<Output>
Creates `.metapowers/branding/<brand>/05-guidelines.md` containing:

- Brand overview (purpose, vision, mission, values)
- Logo usage rules and variations
- Color palette with specifications
- Typography system
- Imagery guidelines
- Voice and tone summary
- Compliance rules
- Asset inventory
</Output>

## After Guidelines

Use [Audit](/docs/branding/audit) to score any content against these guidelines.
