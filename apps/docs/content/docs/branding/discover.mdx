## Purpose

The Discover phase gathers insights about the business, audience, competitors, and market. It asks key questions and conducts research to build a foundation for brand strategy.

## Usage

**Example:**
```
/branding:discover acme
```

## What It Does

<Steps>
<Step>Asks discovery questions about the business, audience, goals, and aspirations</Step>
<Step>Audits existing brand assets if they exist (logo, colors, messaging)</Step>
<Step>Researches competitor brands via web search</Step>
<Step>Builds audience personas with needs and pain points</Step>
<Step>Writes findings to `.metapowers/branding/<brand>/01-discover.md`</Step>
</Steps>

## Output

<Output>
Creates `.metapowers/branding/<brand>/01-discover.md` containing:

- Business overview and goals
- Existing brand audit (if applicable)
- Competitive landscape analysis
- Target audience personas
- Market insights and opportunities
</Output>
