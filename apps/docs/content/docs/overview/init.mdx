## Purpose

The Init skill sets up the `.singularskills/` directory for a new project. It creates the directory structure and lets you choose which domains to activate.

## What It Does

<Steps>
<Step>Creates the `.singularskills/` root directory</Step>
<Step>Asks for your project name</Step>
<Step>Presents all available domains — you pick which ones to use</Step>
<Step>Creates subdirectories for selected domains</Step>
<Step>Writes a project config to `.singularskills/config.md`</Step>
<Step>Suggests which domain to start with</Step>
</Steps>

## Available Domains

| Domain | What It Does |
|--------|-------------|
| Design | Component design with Figma integration |
| Research | Double Diamond discovery and validation |
| Development | Plan, build, test, debug, review, ship |
| Marketing | RACE Framework campaigns |
| Branding | Brand creation and compliance |
| Accessibility | WCAG-EM audits |
| Project Management | Scrum workflow |
| Coaching | Domain-specific mentorship |
| Leadership | Team development and management |
| Legal | Contracts, compliance, governance |

## Project Config

The init skill creates `.singularskills/config.md` containing:
- Project name
- Active domains
- Date initialized
- Notes or goals
