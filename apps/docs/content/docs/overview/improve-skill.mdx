## Purpose

Refine an existing skill based on feedback and updated best practices. Works with both built-in singularskills skills and custom skills.

## Usage

**Examples:**
```
/singular-improve-skill design:empathize
/singular-improve-skill .claude/skills/flutter-testing/SKILL.md
```

## What It Does

<Steps>
<Step>Reads the current SKILL.md</Step>
<Step>Asks what didn't work well or what could be better</Step>
<Step>Reviews any artifacts the skill previously produced</Step>
<Step>Researches updated best practices</Step>
<Step>Rewrites the skill with improvements</Step>
<Step>Validates and saves</Step>
</Steps>

## Iterative Improvement

Skills get better over time. Each time you use a skill and notice something could be improved, run `/singular-improve-skill` with your feedback. The skill is updated in place, preserving backward compatibility with existing artifacts. Custom skills live at `.claude/skills/<skill-name>/SKILL.md` and are available as `/<name>` in the next Claude Code session.
