---
title: Installation
description: How to install and configure Metapowers across AI coding assistants.
---

Metapowers works with multiple AI coding tools. Choose your tool below.

## Claude Code

The native experience. Install from the marketplace, inside Claude Code:

```
/plugin marketplace add bromso/metapowers
/plugin install design@metapowers
```

Or from a shell:

```bash
claude plugin marketplace add bromso/metapowers && claude plugin install design@metapowers
```

Repeat the install line for any other domain (`research`, `development`, `legal`, …). Verify with:

```
/design:empathize test-component
```

### Updating

```
/plugin marketplace update metapowers
/plugin update design@metapowers
```

## Codex CLI

```bash
npx create-metapowers --tool codex
```

This copies the selected domains to `.metapowers/plugins/<domain>/` and creates `AGENTS.md`, which Codex reads automatically from your project root.

## OpenCode

```bash
npx create-metapowers --tool opencode
```

This copies the selected domains to `.metapowers/plugins/<domain>/` and creates `AGENTS.md`, which OpenCode reads automatically from your project root.

## Cursor

```bash
npx create-metapowers --tool cursor
```

This copies the selected domains to `.cursor/skills/metapowers/<domain>/` and creates `.cursorrules`, which Cursor loads automatically from your project root.

## Configure Figma Access (Optional)

The Design plugin writes prototypes to Figma via MCP. Set your Figma access token:

```bash
export FIGMA_ACCESS_TOKEN="your-token-here"
```

Add this to your shell profile (`.zshrc`, `.bashrc`) to persist it. This is only needed for the Design plugin's Figma integration.

## Verify Installation

Run any skill to confirm everything works:

```
/design:empathize test-component
```

You should see the empathize phase execute, creating artifacts in `.metapowers/design/test-component/`.

## Compatibility

| Tool | Instructions File | Skills Format | Native Support |
|------|------------------|---------------|----------------|
| Claude Code | `CLAUDE.md` | SKILL.md with YAML frontmatter | Yes |
| Codex CLI | `AGENTS.md` | SKILL.md with YAML frontmatter | Yes |
| OpenCode | `AGENTS.md` | SKILL.md with YAML frontmatter | Yes |
| Cursor | `.cursorrules` | SKILL.md (manual reference) | Partial |

All tools share the same SKILL.md format with YAML frontmatter. The skills themselves are tool-agnostic — they're structured markdown prompts that work in any AI coding environment.
