## What is singularskills?

singularskills is one pack of agent skills that turns production work into repeatable workflows for your coding agent. Each domain follows a named methodology, such as design thinking, Scrum or NIST CSF 2.0, with one skill per phase. Each phase writes an artifact to `.singularskills/<workflow>/<project>/`, and gates stop you skipping steps.

The grid at the end of this page lists every domain. Each domain's index page explains its phases and the artifacts they write.

## Quick Start

Install the pack into your project (any agent; see [Installation](/docs/overview/installation) for the Claude Code and Codex marketplaces):

```bash
npx skills add bromso/singularskills
```

Then start a design workflow:

```
/workflow design button
```

The conductor runs the empathize phase for a "button" component, writes `.singularskills/design/button/01-empathize.md`, and stops to ask whether to approve the phase before it moves on. To run a single phase on its own, invoke its skill, for example `/design-empathize button`.

## How It Works

Each domain provides:

- **Phases**: ordered steps in a methodology (e.g., empathize → define → ideate → prototype → test), listed in a workflow file
- **Skills**: one per phase or utility, each a structured prompt your agent follows
- **Gates**: checks that a phase's required artifacts exist before it writes
- **Artifacts**: Markdown files written at each phase, under `.singularskills/design/` (or the workflow's own folder), plus a run log of every run and approval
