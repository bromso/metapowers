## Purpose

Create a brand-new skill for any topic. Researches best practices and generates a structured SKILL.md following Metapowers conventions.

## Usage

**Example:**
```
/metapowers:create-skill flutter widget testing with golden files
```

## What It Does

<Steps>
<Step>Clarifies requirements with the user if needed</Step>
<Step>Researches current best practices via web search</Step>
<Step>Creates a SKILL.md with proper frontmatter, process steps, and output format</Step>
<Step>Validates against skill-validator rules (`name` matches the directory, verb-first description with a "Use when" clause, 120–400 characters)</Step>
<Step>Installs to `.claude/skills/<skill-name>/SKILL.md` — the skill is available as `/<name>` in the next Claude Code session</Step>
</Steps>

## Skill Format

Created skills follow the standard Metapowers pattern:
- YAML frontmatter: `name` (the directory name), a `description` shaped `<Verb-first sentence>. Use when <the user's situation, at least six words>.` with an optional `Not for <adjacent thing>; see /<plugin>:<skill>.` (120–400 characters), and `argument-hint` when the skill takes an argument
- Prerequisites section
- Numbered process steps
- Output section with artifact path
