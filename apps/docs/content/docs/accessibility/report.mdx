## Purpose

The Report phase transforms raw evaluation findings into a structured audit report with an executive summary, detailed findings, and prioritized remediation steps.

## Usage

**Example:**
```
/accessibility-report checkout-flow
```

## Prerequisites

Requires `.singularskills/accessibility/<target>/02-evaluate.md` from the Evaluate phase. Use `--skip-checks` to bypass.

## What It Does

<Steps>
<Step>Creates an executive summary with overall conformance status</Step>
<Step>Documents each finding with description, WCAG criterion, severity, impact, and fix steps</Step>
<Step>Includes before/after code examples where applicable</Step>
<Step>Prioritizes remediation: critical first, then major, then minor</Step>
<Step>Estimates fix effort (quick fix vs. significant rework)</Step>
<Step>Writes the report to `.singularskills/accessibility/<target>/03-report.md`</Step>
</Steps>

## Output

<Output>
Creates `.singularskills/accessibility/<target>/03-report.md` containing:

- Executive summary with conformance status
- Detailed findings grouped by WCAG principle
- Remediation steps with code examples
- Prioritized action plan with effort estimates
</Output>
