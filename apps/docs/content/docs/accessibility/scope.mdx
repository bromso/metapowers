## Purpose

The Scope phase defines what to audit, which WCAG level to target, and which pages or features to include. A well-defined scope ensures the audit is focused and actionable.

## Usage

**Example:**
```
/accessibility-scope checkout-flow
```

## What It Does

<Steps>
<Step>Clarifies the audit target (website, app, component, or feature)</Step>
<Step>Determines the WCAG conformance level (A, AA, or AAA)</Step>
<Step>Identifies specific pages and features to test</Step>
<Step>Defines the testing approach (automated + manual)</Step>
<Step>Documents known accessibility concerns</Step>
<Step>Writes the scope to `.singularskills/accessibility/<target>/01-scope.md`</Step>
</Steps>

## Output

<Output>
Creates `.singularskills/accessibility/<target>/01-scope.md` containing:

- Audit target description
- WCAG level and compliance requirements
- Pages and features in scope
- Testing methods
- Known concerns to prioritize
</Output>
