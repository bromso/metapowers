## Purpose

The Retest phase verifies that fixes are effective, checks for regressions, and produces a formal WCAG conformance statement.

## Usage

**Example:**
```
/accessibility-retest checkout-flow
```

## Prerequisites

Requires `.singularskills/accessibility/<target>/04-remediate.md` from the Remediate phase. Use `--skip-checks` to bypass.

## What It Does

<Steps>
<Step>Re-evaluates each fixed issue to verify resolution</Step>
<Step>Runs regression checks across all WCAG criteria</Step>
<Step>Verifies keyboard navigation flow end-to-end</Step>
<Step>Checks for new issues introduced by fixes</Step>
<Step>Produces a formal conformance statement</Step>
<Step>Writes results to `.singularskills/accessibility/<target>/05-retest.md`</Step>
</Steps>

## Output

<Output>
Creates `.singularskills/accessibility/<target>/05-retest.md` containing:

- Verification results per issue
- Regression check findings
- Formal WCAG conformance declaration
- Remaining known issues (if any)
- Maintenance and monitoring recommendations
</Output>
