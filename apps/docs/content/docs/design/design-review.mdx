## Purpose

The design review utility generates a Figma Slides presentation that summarizes a component's full design journey: research, definition, ideation, prototyping, and testing. Use it when you need to present a component's design work to stakeholders or walk a team through it.

Not for feedback on a design in progress — see `/coaching-ux` or `/design-test`.

## Usage

**Example:**
```
/design-design-review button
```

`--skip-checks` skips the prerequisite check and logs a `skipped` event to `.singularskills/log.jsonl`.

## Prerequisites

At least the Define phase (`.singularskills/design/<project>/02-define.md`) should exist. More completed phases produce a richer presentation.

## What It Does

<Steps>
<Step>Reads all available phase artifacts for the project (empathize, define, ideate, prototype, test)</Step>
<Step>Creates a title slide with the component name and date</Step>
<Step>Creates one slide per completed phase, summarizing its key findings — exporting an image of the prototype if one exists</Step>
<Step>Creates a summary slide with overall pass/fail status, key decisions, and next steps</Step>
<Step>Sets a dissolve transition across the slides</Step>
<Step>Presents the slide deck info, including slide count and a link to view it in Figma</Step>
</Steps>

## Output

<Output>
A Figma Slides presentation created in the current file, summarizing the design journey for the project.
</Output>
