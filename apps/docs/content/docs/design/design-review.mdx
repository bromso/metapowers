## Purpose

The design review utility generates a Figma Slides presentation that summarizes a component's full design journey: research, definition, ideation, prototyping, and testing. Use it when you need to present a component's design work to stakeholders or walk a team through it.

Not for feedback on a design in progress — see `/coaching:ux` or `/design:test`.

## Usage

```
/design:design-review <project> [--skip-checks]
```

**Example:**
```
/design:design-review button
```

`--skip-checks` skips the prerequisite check and logs the skip to `.metapowers/design/<project>/skip-log.md`.

## Prerequisites

At least the Define phase (`.metapowers/design/<project>/02-define.md`) should exist. More completed phases produce a richer presentation.

## What It Does

1. Reads all available phase artifacts for the project (empathize, define, ideate, prototype, test)
2. Creates a title slide with the component name and date
3. Creates one slide per completed phase, summarizing its key findings — exporting an image of the prototype if one exists
4. Creates a summary slide with overall pass/fail status, key decisions, and next steps
5. Sets a dissolve transition across the slides
6. Presents the slide deck info, including slide count and a link to view it in Figma

## Output

A Figma Slides presentation created in the current file, summarizing the design journey for the project.
