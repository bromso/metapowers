## Purpose

The system overview utility gives a comprehensive summary of the design system in a Figma file: components, styles, token collections and modes, and page structure. Use it when you're new to a Figma design system or want to know what it contains before working with it.

Not for exporting tokens as code — see `/design:export-tokens`.

## Usage

Provide a Figma file key or URL.

## What It Does

<Steps>
<Step>Identifies the Figma file</Step>
<Step>Calls `figma_get_design_system_summary` for counts and page structure</Step>
<Step>Calls `figma_get_styles` to list all published styles</Step>
<Step>Calls `figma_get_components` to list all published components</Step>
<Step>Calls `figma_get_variables` (JSON format) to get token structure</Step>
<Step>Compiles the overview: file info, components, styles (by type), tokens (collections, variables by type, mode names), and page structure</Step>
<Step>Presents the overview to the user</Step>
</Steps>

## Output

<Output>
A structured design system overview presented to the user, useful for onboarding onto or auditing the state of a design system.
</Output>
