## Purpose

The ideate phase generates multiple design options before committing to an implementation. This prevents jumping to the first solution and encourages creative exploration.

## Prerequisites

Requires `.singularskills/design/<component-name>/02-define.md` (the component contract) from Phase 2. Its gate script (`scripts/gate.sh`) stops the skill if it is missing; `--skip-checks` bypasses it after logging a `skipped` event to `.singularskills/log.jsonl`.

## What It Does

<Steps>
<Step>Reads the component contract</Step>
<Step>Generates 3+ distinct design approaches</Step>
<Step>Evaluates each against the contract's constraints</Step>
<Step>Recommends one approach with rationale</Step>
<Step>Boards the options on a FigJam board when the request gives a board link and *Figma* is bound; otherwise the comparison matrix in the artifact is the board</Step>
<Step>Writes to `.singularskills/design/<component-name>/03-ideate.md`</Step>
</Steps>

## Output

<Output>
Creates `.singularskills/design/<component-name>/03-ideate.md` containing:

- Multiple design options with visual descriptions
- Trade-off analysis for each option
- Constraint compliance evaluation
- Recommended approach and reasoning
</Output>
