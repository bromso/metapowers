## Purpose

The ideate phase generates multiple design options before committing to an implementation. This prevents jumping to the first solution and encourages creative exploration.

## Prerequisites

Requires `.metapowers/design/<component-name>/component-contract.md` from Phase 2.

## What It Does

<Steps>
<Step>Reads the component contract</Step>
<Step>Generates 3+ distinct design approaches</Step>
<Step>Evaluates each against the contract's constraints</Step>
<Step>Recommends one approach with rationale</Step>
<Step>Optionally creates a FigJam brainstorming board with `figjam_create_stickies` and `figjam_create_table`</Step>
<Step>Writes to `.metapowers/design/<component-name>/ideation-options.md`</Step>
</Steps>

## Output

<Output>
Creates `.metapowers/design/<component-name>/ideation-options.md` containing:

- Multiple design options with visual descriptions
- Trade-off analysis for each option
- Constraint compliance evaluation
- Recommended approach and reasoning
</Output>

## MCP Tools Used

<Requires
	mcp={[
		{ name: "figma_get_design_system", description: "Fetch the full design system (styles, components, tokens)" },

		{ name: "figjam_create_stickies", description: "Create sticky notes on a FigJam board for brainstorming" },
		{ name: "figjam_create_table", description: "Create a comparison table on a FigJam board" },
