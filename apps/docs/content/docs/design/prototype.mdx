## Purpose

The prototype phase takes the chosen design from ideation and builds it as a Figma component when a Figma MCP server is bound, and as a build sheet when none is.

## Prerequisites

- `.singularskills/design/<component-name>/02-define.md` (the component contract, from Phase 2)
- `.singularskills/design/<component-name>/03-ideate.md` (the chosen approach, from Phase 3)

Its gate script (`scripts/gate.sh`) stops the skill if either file is missing; `--skip-checks` bypasses it after logging a `skipped` event to `.singularskills/log.jsonl`. In Claude Code the gate hook enforces the same check on the write.
- Optionally a Figma MCP server connected to your agent (see [Figma](/docs/design/figma))

## What It Does

<Steps>
<Step>Reads the component contract and chosen ideation option</Step>
<Step>Reads the tokens the contract names (*Figma*: `read-tokens`; without Figma: the project's own token sources)</Step>
<Step>Builds the component (*Figma*: `write-design`, following the Plugin API patterns in the bundled capability reference; without Figma: a build sheet with every variant and state, the auto layout and the variant grid)</Step>
<Step>Verifies it (*Figma*: a screenshot against the contract; without Figma: the build sheet against the contract)</Step>
<Step>Writes notes to `.singularskills/design/<component-name>/04-prototype.md`</Step>
</Steps>

## Figma

The prototype phase writes to your Figma canvas through the `write-design` capability of a Figma MCP server you connect yourself, and records the created node ids in the artifact's `## Tools` section; see [Figma](/docs/design/figma). Its gate checks that the component contract (`02-define.md`) and the ideation (`03-ideate.md`) exist before it writes.

## Output

<Output>
- Figma component created on your canvas, or a build sheet in the artifact
- `.singularskills/design/<component-name>/04-prototype.md` with implementation notes
</Output>
