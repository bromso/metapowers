## Purpose

The prototype phase takes the chosen design from ideation and builds it as a Figma component using the Figma MCP server.

## Prerequisites

- `.singularskills/design/<component-name>/component-contract.md` (hard gate — enforced by hook)
- `.singularskills/design/<component-name>/ideation-options.md` (soft gate)
- A Figma MCP server configured in your agent (see the [design workflow](/docs/design) page)

## What It Does

<Steps>
<Step>Reads the component contract and chosen ideation option</Step>
<Step>Creates the component structure with `figma_create_component` and `figma_create_frame`</Step>
<Step>Adds text layers with `figma_create_text` and shapes with `figma_create_shape`</Step>
<Step>Configures layout with `figma_set_auto_layout` and applies styles with `figma_apply_styles`</Step>
<Step>Arranges variant sets with `figma_arrange_component_set`</Step>
<Step>Exports preview images with `figma_export_image`</Step>
<Step>Writes notes to `.singularskills/design/<component-name>/prototype-notes.md`</Step>
</Steps>

## Figma MCP Integration

The prototype phase writes to your Figma canvas through the `figma_*` tools of a Figma MCP server you configure in your agent. Its gate checks that the component contract (`02-define.md`) and the ideation (`03-ideate.md`) exist before it writes.

## Output

<Output>
- Figma component created on your canvas
- `.singularskills/design/<component-name>/prototype-notes.md` with implementation notes
</Output>
