## Purpose

The prototype phase takes the chosen design from ideation and builds it as a Figma component using the Figma MCP server.

## Prerequisites

- `.metapowers/design/<component-name>/component-contract.md` (hard gate — enforced by hook)
- `.metapowers/design/<component-name>/ideation-options.md` (soft gate)
- A Figma access token

Claude Code asks for the Figma access token when you enable the design plugin; you can set or change it later from the plugin's configuration in the `/plugin` menu. The `FIGMA_ACCESS_TOKEN` environment variable is no longer used.

## What It Does

<Steps>
<Step>Reads the component contract and chosen ideation option</Step>
<Step>Creates the component structure with `figma_create_component` and `figma_create_frame`</Step>
<Step>Adds text layers with `figma_create_text` and shapes with `figma_create_shape`</Step>
<Step>Configures layout with `figma_set_auto_layout` and applies styles with `figma_apply_styles`</Step>
<Step>Arranges variant sets with `figma_arrange_component_set`</Step>
<Step>Exports preview images with `figma_export_image`</Step>
<Step>Writes notes to `.metapowers/design/<component-name>/prototype-notes.md`</Step>
</Steps>

## Figma MCP Integration

The Design plugin uses `@anthropic-ai/figma-mcp` to write directly to your Figma canvas. A `PreToolUse` hook ensures a component contract exists before any Figma write operation.

## Output

<Output>
- Figma component created on your canvas
- `.metapowers/design/<component-name>/prototype-notes.md` with implementation notes
</Output>
