## Purpose

The define phase synthesizes empathize research into a concrete component contract — a specification document that drives all subsequent design and implementation.

## Prerequisites

Requires `.singularskills/design/<component-name>/01-empathize.md` from Phase 1. Its gate script (`scripts/gate.sh`) stops the skill if it is missing; `--skip-checks` bypasses it after logging a `skipped` event to `.singularskills/log.jsonl`.

## What It Does

<Steps>
<Step>Reads the empathize brief</Step>
<Step>Reads the design system via `figma_get_design_system` and `figma_get_variables`</Step>
<Step>Defines variants, states, props, and constraints</Step>
<Step>Specifies accessibility requirements</Step>
<Step>Writes to `.singularskills/design/<component-name>/02-define.md`</Step>
</Steps>

## Output

<Output>
Creates `.singularskills/design/<component-name>/02-define.md` (the component contract) containing:

- Component name and purpose
- Variants and states
- Props/API surface
- Accessibility requirements (from WCAG criteria)
- Visual specifications
- Interaction patterns
</Output>

## Gate

The define phase output, `02-define.md`, is required by the ideate and prototype phases: their gates refuse to run until it exists.
