## Purpose

The empathize phase researches the problem space before any design work begins. It gathers user needs, existing patterns, accessibility requirements, and contextual constraints.

## Usage

**Example:**
```
/design-empathize button
```

## What It Does

<Steps>
<Step>Researches common patterns for the component type</Step>
<Step>Reads the design system (*Figma*: tokens, components, related nodes and screenshots; without Figma: the project's own token and component sources, else a **Not checked** note)</Step>
<Step>Identifies user needs and use cases</Step>
<Step>Reviews accessibility requirements (WCAG criteria)</Step>
<Step>Documents existing implementations and prior art</Step>
<Step>Writes findings to `.singularskills/design/<component-name>/01-empathize.md`</Step>
</Steps>

## Output

<Output>
Creates `.singularskills/design/<component-name>/01-empathize.md` containing:

- User needs and pain points
- Existing pattern analysis
- Accessibility considerations
- Contextual constraints
- Recommended approach
</Output>
