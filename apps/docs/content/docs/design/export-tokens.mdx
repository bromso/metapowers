## Purpose

The export tokens utility pulls design tokens (variables) out of a Figma file and converts them into a code-ready format. Use it when you want Figma colors, spacing, and type values in code, or when you have a Figma URL and want its tokens.

Not for a full inventory of the whole design system — see `/design-system-overview`.

## Usage

Provide a Figma file key or URL, and optionally a format (`css`, `tailwind`, or `json`; defaults to `css`).

## What It Does

<Steps>
<Step>Identifies the Figma file, extracting the file key from a URL if needed</Step>
<Step>Reads the file's variables and styles (*Figma*: `read-tokens`; without Figma: says the file could not be read and exports nothing) and converts them itself to the requested format</Step>
<Step>Presents the exported tokens to the user</Step>
<Step>Optionally saves the output to a file (`tokens.css`, `tailwind.tokens.json`, or `tokens.json`, matching the format)</Step>
</Steps>

## Output

<Output>
The exported tokens displayed to the user and optionally saved to a file.
</Output>
