The design domain follows design thinking in five phases: empathize, define, ideate, prototype and test. You run one slash command per phase for each component. Each phase writes a numbered artifact to `.singularskills/design/<project>/`, from `01-empathize.md` to `05-test.md`. The prototype phase builds the component in Figma when a Figma MCP server is connected, and writes a build sheet when none is.

## The Five Phases

| Phase | Command | Purpose |
|-------|---------|---------|
| Empathize | `/design-empathize` | Research user needs, context, and existing patterns |
| Define | `/design-define-component` | Create a component contract with specs and constraints |
| Ideate | `/design-ideate` | Explore multiple design approaches |
| Prototype | `/design-prototype` | Build the component in Figma, or write a build sheet |
| Test | `/design-test` | Validate against WCAG and component contract |

## Artifact Flow

Each phase reads from previous phases and writes to `.singularskills/design/<component-name>/`:

```
.singularskills/design/button/
  01-empathize.md   ← Phase 1 output
  02-define.md      ← Phase 2 output (the component contract)
  03-ideate.md      ← Phase 3 output
  04-prototype.md   ← Phase 4 output
  05-test.md        ← Phase 5 output
```

Run the whole sequence with `/workflow design button`: the conductor runs one phase at a time and stops for your approval at each boundary (see [Workflows](/docs/overview/workflows)).

## Quality Gates

Phases 2 to 5 each ship a gate script, `scripts/gate.sh`, which the skill runs before it writes. If a required earlier artifact is missing (for example `02-define.md` before ideation), the skill stops and tells you which phase to run. In Claude Code, the plugin's gate hook runs the same check before any write into `.singularskills/`.

Pass `--skip-checks` to go ahead anyway. The skill first records a `skipped` event in `.singularskills/log.jsonl`, so a bypass is never silent.

## Figma

Nine design skills have steps marked *Figma*. Each names a capability (read tokens, find components, read or screenshot a node, write to the canvas, a board or a deck), binds it at run time to a Figma MCP server you connect yourself, and states what it does without one; the pack ships no server and makes no network calls. See [Figma](/docs/design/figma) for connecting Figma's server and the capability table.
