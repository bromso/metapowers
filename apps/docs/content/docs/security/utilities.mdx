## Purpose

Utility skills work across all Security Lifecycle phases. They have no prerequisites and can be run anytime — for security checklists, threat research, compliance mapping, training development, or penetration test planning.

## Skills

### Security Checklist

<Command>
{"/security-security-checklist <topic>"}
</Command>

Generates security checklists tailored to specific projects, releases, or environments. Covers pre-deployment checks, security review gates, and launch readiness criteria.

<Output>**Output:** Security checklist with categorized verification items → `.singularskills/security/<topic>/security-checklist.md`</Output>

### Threat Intel

<Command>
{"/security-threat-intel <topic>"}
</Command>

Researches threat intelligence for specific technologies, industries, or threat actors. Provides structured analysis of relevant threats, TTPs, and recommended countermeasures.

<Output>**Output:** Threat intelligence report with TTP analysis → `.singularskills/security/<topic>/threat-intel.md`</Output>

### Compliance Map

<Command>
{"/security-compliance-map <topic>"}
</Command>

Maps security controls to compliance framework requirements. Supports SOC 2, ISO 27001, PCI DSS, HIPAA, NIST 800-53, and other frameworks with control cross-references.

<Output>**Output:** Compliance mapping with control cross-references → `.singularskills/security/<topic>/compliance-map.md`</Output>

### Security Training

<Command>
{"/security-security-training <topic>"}
</Command>

Creates security awareness training materials for development teams and staff. Covers secure development practices, phishing awareness, data handling, and role-specific training modules.

<Output>**Output:** Training materials with modules and assessment criteria → `.singularskills/security/<topic>/security-training.md`</Output>

### Pentest Plan

<Command>
{"/security-pentest-plan <topic>"}
</Command>

Plans penetration testing engagements. Covers scope definition, rules of engagement, testing methodology, tool selection, reporting requirements, and remediation timelines.

<Output>**Output:** Penetration test plan with scope and methodology → `.singularskills/security/<topic>/pentest-plan.md`</Output>
