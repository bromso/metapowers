## Purpose

Facilitate a structured team retrospective using the Start/Stop/Continue format with root cause analysis and actionable outcomes.

## Usage

**Example:**
```
/leadership-retro sprint 12
```

## What It Does

<Steps>
<Step>Structures reflection: Start (new practices), Stop (drop), Continue (keep)</Step>
<Step>Identifies root causes and recurring patterns</Step>
<Step>Converts insights into 2-3 assignable action items with owners and deadlines</Step>
<Step>Writes to `.singularskills/leadership/<topic>/retro.md`</Step>
</Steps>
