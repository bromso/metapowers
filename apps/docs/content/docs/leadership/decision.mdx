## Purpose

Work through a decision using the appropriate framework — decide alone, consult, delegate, or seek consensus based on impact and urgency.

## Usage

**Example:**
```
/leadership:decision rewrite auth system or patch it
```

## What It Does

<Steps>
<Step>Determines the right decision mode (impact/urgency matrix)</Step>
<Step>Analyzes options with pros, cons, risks, and reversibility</Step>
<Step>Makes a recommendation with monitoring plan and rollback strategy</Step>
<Step>Writes to `.metapowers/leadership/<topic>/decision.md`</Step>
</Steps>
