## Purpose

Structure delegation with clear ownership, authority boundaries, check-in cadence, and done criteria.

## Usage

**Example:**
```
/leadership-delegate API migration to backend team
```

## What It Does

<Steps>
<Step>Defines the deliverable and why it matters</Step>
<Step>Matches to the right person based on skills and growth opportunity</Step>
<Step>Sets authority level, support resources, check-in schedule, and done criteria</Step>
<Step>Writes to `.singularskills/leadership/<topic>/delegation.md`</Step>
</Steps>
