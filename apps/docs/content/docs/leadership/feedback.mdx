## Purpose

Prepare structured feedback using the SBI (Situation, Behavior, Impact) model and the CFR (Conversations, Feedback, Recognition) framework.

## Usage

**Example:**
```
/leadership-feedback missed deadline on API migration
```

## What It Does

<Steps>
<Step>Structures feedback using SBI: specific situation, observable behavior, concrete impact</Step>
<Step>Adds feedforward guidance (what to do differently)</Step>
<Step>Prepares delivery notes with tone guidance and anticipated reactions</Step>
<Step>Writes to `.singularskills/leadership/<topic>/feedback.md`</Step>
</Steps>
