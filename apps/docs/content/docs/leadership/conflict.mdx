## Purpose

Work through a team conflict by understanding perspectives, finding root causes, and planning a constructive resolution conversation.

## Usage

**Example:**
```
/leadership-conflict engineers disagree on architecture approach
```

## What It Does

<Steps>
<Step>Maps each party's perspective and underlying concerns</Step>
<Step>Identifies root cause (roles, priorities, communication, values, or resources)</Step>
<Step>Develops resolution options that address core concerns</Step>
<Step>Plans the facilitation conversation with ground rules</Step>
<Step>Writes to `.singularskills/leadership/<topic>/conflict-resolution.md`</Step>
</Steps>
