## Purpose

The empathize phase researches the problem space before any design work begins. It gathers user needs, existing patterns, accessibility requirements, and contextual constraints.

## Usage

Run the phase with the name of the component you are researching.

```
/design:empathize <component-name>
```

**Example:**
```
/design:empathize button
```

## What It Does

1. Researches common patterns for the component type. Compares how other design systems name and structure it.
2. Uses `figma_get_design_system` and `figma_get_components` to research existing patterns in the Figma file
3. Identifies user needs and use cases. Notes who uses the component, where, and why!
4. Writes findings to `.singularskills/design/<component-name>/empathize-brief.md`

## Output

Creates `.singularskills/design/<component-name>/empathize-brief.md` containing:

- User needs and pain points
- Existing pattern analysis
