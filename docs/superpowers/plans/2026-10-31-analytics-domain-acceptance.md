# Analytics domain: acceptance record

Plan: `2026-10-31-analytics-domain.md`. Spec: `docs/superpowers/specs/2026-10-31-analytics-domain-design.md` §9. Branch `analytics-domain`, verified 2026-10-31 on macOS with Claude Code, the pack loaded from this worktree with `--plugin-dir`, no MCP servers (`--strict-mcp-config --mcp-config '{"mcpServers":{}}'`), `--allowedTools Read,Write,Edit,Glob,Grep,Skill,Bash --max-turns 40`, every prompt ending "I won't be around to answer questions".

Data, all synthetic and generated by a seeded script:
- `orders.csv`: 500 orders with user IDs, `@example.com` emails, refunds, negative amounts and duplicate keys.
- Three experiment results: a clean 50/50 test; a 90/10 test that matches its plan; a 50/50-planned test observed at 54/46.
- `weekly.csv`: conversion falls from 4.4% to 3.5% while both segments rise.
- `daily-orders.csv`: the true average order value is £36.85; the mean of the daily averages is £59.10.
