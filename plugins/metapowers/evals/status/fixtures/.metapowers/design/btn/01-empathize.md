# Empathize — btn

Research brief for the primary button component.

## User Needs
- One clear primary action per view; secondary and destructive variants.
- Works with keyboard and screen readers; visible focus ring.

## Existing Patterns
- Unstyled HTML buttons with inline styles; no shared component.

## Accessibility Requirements
- WCAG 2.1 AA: 4.5:1 text contrast, 2.4.7 focus visible, accessible name on icon-only buttons.
